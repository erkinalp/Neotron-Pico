# Neotron-Pico microBTX Conversion

This directory contains specifications and documentation for converting the Neotron-Pico from ATX to microBTX form factor.

## Files
- `board_transformation_spec.md`: Detailed specifications for the board transformation
- `implementation_approach.md`: Recommended tools and implementation steps
- `component_classification.md`: Classification of components for the conversion process

## Purpose
The microBTX conversion is intended to provide a usable passively cooled motherboard for users with BTX computers. The conversion follows Intel's microBTX form factor specifications and ensures compatibility with BTX cases.

## Implementation Status
This is a specification document for the conversion process. The actual implementation requires KiCad expertise and appropriate tools for PCB design modification.
